## FAQ

**1) Will this work with Netflix?**  
It’s built around the **private vpn for netflix** use case. Results still depend on server choice and current platform blocking—switch servers if needed.

The project is positioned around a **No-Logs policy**. Use the official build and documentation on the landing page for the current policy statement.

**3) What happens if the VPN drops mid-stream?**  
Enable **Kill Switch**. It cuts traffic to prevent leaks until the tunnel is back.

**4) Which server should I pick first?**  
Start with the closest **Global Servers** location for speed. If playback fails, try another region/server—don’t brute-force one endpoint.
